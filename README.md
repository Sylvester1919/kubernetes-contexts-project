# kubernetes-contexts-project
Hands-on Kubernetes project demonstrating context-based environment management using namespaces, context switching, and real application deployments

# Kubernetes Contexts Project

## Objective
To manage multiple environments using Kubernetes contexts
and prevent accidental deployments.

## What This Project Shows
- Use of Kubernetes contexts
- Namespace isolation
- Safe environment management

## Tools Used
- Kubernetes
- kubectl
- Minikube

## Project Flow
1. Create namespaces
2. Create contexts
3. Switch contexts
4. Deploy applications
5. Verify isolation

## Outcome
Each environment runs independently using Kubernetes contexts.
